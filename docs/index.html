macOS First-Launch Note

Because Lor is an open-source build without an expensive commercial Apple Developer ID certificate, macOS Gatekeeper may alert you upon opening. If prompted with "Lor is damaged or can't be opened", simply open Terminal and run:

xattr -cr /Applications/Lor.app
