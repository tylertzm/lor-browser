macOS First-Launch Note

Because Lor is an open-source build without an Apple Developer ID signature, macOS Gatekeeper may show a warning on first launch. If prompted with "Lor is damaged or can't be opened", run this single command in Terminal:

xattr -cr /Applications/Lor.app
macOS Gatekeeper Guide • Read Before Launching

Opening Lor on macOS

Why macOS displays "Lor is damaged":
Because Lor is 100% free and community open-source without an expensive commercial Apple Developer ID ($99/year), macOS Gatekeeper tags unsigned internet downloads with a false "damaged" warning on first launch. Your build is completely safe, unmodified, and private.
Step 1: Run Once in Terminal (100% Works)
xattr -cr /Applications/Lor.app
Alternative GUI Method (No Terminal):
Open System Settings → Privacy & Security, scroll down to the Security section, and click "Open Anyway".
